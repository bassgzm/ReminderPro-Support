# Reminder Pro: Support & Privacy

The public support and privacy pages for **Reminder Pro**, an iPhone and iPad reminders app with customizable snooze, published with GitHub Pages.

- **Support:** https://bassgzm.github.io/ReminderPro-Support/
- **Privacy Policy:** https://bassgzm.github.io/ReminderPro-Support/privacy.html
- **Contact:** reminderpro.support@icloud.com

## Files

| File | Page |
|---|---|
| `index.html` | Support page: contact and common questions |
| `privacy.html` | Privacy policy (linked from the App Store listing) |
| `.nojekyll` | Tells GitHub Pages to publish the files as-is |

## Updating

Edit the HTML, commit and push to `main`. GitHub Pages republishes in a minute or two.
When the privacy policy changes, update its "Effective" date and keep the copy in the app's private repo (`docs/privacy.html`) in sync.

This repo holds only these web pages; the app's source code is private.
